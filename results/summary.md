## Limits

- n per cell is 5 (fewer where pages are missing). A count like 3 of 5 versus 1 of 5 is well within what repeated runs of the same model and prompt can produce.
- One prompt wording per site type. Other wordings could give other pages.
- P1 run 1 of every model is the pilot page, generated about an hour before the main run with the same settings; it is counted like any other run.
- Pages were rendered on Linux, where Mac and Windows system fonts are not installed, so they are drawn with substitutes. Font counts use the declared font (what the page asked for), not what was drawn; the screenshots show the substitutes.
- The measurer's rules were tuned on 21 project-management pages (the pilot). They may misread restaurant, photographer and law-firm pages (P2-P4), for example what counts as a feature card or a section label.
- Each CLI ran with its own default instructions (README, "Keeping the harness out of it"). The Codex models therefore saw Codex's built-in "Frontend Design Guidance", including a list of suggested fonts; the Claude and Gemini models saw their own CLI's instructions. Differences between vendors may come from those instructions rather than the models.
- For Gemini the kept page is the first file the model tried to create (the tool call was rejected); the reply it wrote afterwards was not used.
- Everything here is correlational and descriptive: counts of what the pages contain, not causes.
