01 / Methodology

Most project tools reward performative ceremony.

When creating a ticket takes 14 custom dropdown fields, engineers stop updating tickets—and managers start scheduling status meetings to ask what's actually happening.

RULE 01

90-Day Backlog Composting

If an issue hasn't been scheduled into a cycle within 90 days, Cadence automatically archives it. Important problems always resurface; stale wishes only clog search results.

✗ 1,400-ticket "Someday" backlog ✓ Clean 6-week commitment window
RULE 02

Fixed Dates, Variable Scope

Every cycle has a hard ship date and a mandatory 2-week cooldown. When unexpected complexity hits, Cadence forces an explicit scope swap instead of silently sliding deadlines.

✗ "Sprint 44 carryover (again)" ✓ Scope traded before week 4
RULE 03

Days, Never Story Points

Fibonacci poker doesn't survive contact with production. Engineers budget work in real calendar days (0.5d to 5d), directly subtracted from team availability and PTO.

✗ "Is this a 5 or an 8?" ✓ "3 days, shipping Thursday"
02 / System Architecture

Built like a developer tool, not an ERP form.

Every state change in Cadence can be triggered from your terminal, a Git commit trailer, or a local Markdown file.

GIT-NATIVE STATE MACHINE

Issues move when code merges, not when someone remembers to drag a card.

Include Fixes: CAD-412 or Blocks: CAD-415 in your commit message or PR title. Cadence updates cycle burn-up, unblocks dependent owners, and posts the benchmark diff automatically.

Author: Mara Chen <mara@oxide.dev>

ENFORCED COOLDOWN RHYTHM

Six weeks on. Two weeks off to pay down sharp edges.

You cannot schedule feature cycles back-to-back. Cadence locks a 2-week cooldown buffer after every cycle for bug bashes, flaky test cleanup, and writing RFCs for the next cycle.

CAPACITY & SCOPE GUARDRAILS

Add a 4-day task to a full cycle? Pick what gets dropped.

Scope creep happens when additions look free. When a cycle hits 100% of engineer-day capacity, adding a new deliverable requires demoting an equal-sized item back to the cooldown queue.
