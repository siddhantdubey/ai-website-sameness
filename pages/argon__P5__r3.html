02 // ARCHITECTURAL GUARANTEES WHY TEAMS SWITCH FROM JIRA + SPREADSHEETS
02.1 — BI-DIRECTIONAL GIT & CAD

Specs live in the repo, not a walled wiki.

Every Kiln requirement maps 1:1 to a plain Markdown file in your Git repository. Edit a tolerance in a Pull Request, and Kiln automatically flags downstream test owners before merge.

specs/pwr/bms-cutoff.md (PR #418)
- max_discharge_temp_c: 65.0 + max_discharge_temp_c: 58.5
⚠ Triggers re-verification on HIL-RIG-04
02.2 — HARD BLOCKING DAG

Real dependency graphs, not decorative links.

When a PCB layout revision slips by four days, Kiln recalculates critical-path slack across firmware bring-up and enclosure tooling immediately—without a PM manually dragging Gantt bars.

[KLN-402] PCB Rev-C Gerbers +4d slip
└─► [KLN-419] DMA SPI Driver Bringup
└─► [KLN-451] Thermal Chamber Run #2
✓ Auto-notified @m.chen, @s.kline
02.3 — OFFLINE & AIR-GAPPED

Works inside a Faraday cage or factory floor.

Kiln syncs the entire project graph to a local SQLite database in your browser or desktop binary. Triage issues on a flight or inside a shielded lab; changes merge cleanly via CRDTs when you reconnect.
