I've written the landing page to `index.html`. It's one file with no external dependencies, including fonts.

**The product:** "Docket," a project tracker for small teams. The copy has a dry, specific voice, and the hero line is "Projects, minus the theater."

**How I kept it from looking AI-generated:**
- **Look:** warm paper background, black text and one muted red. No purple gradients, frosted-glass panels, glowing blobs or emoji icons.
- **Type:** headings use a serif from the system font stack, with monospace for small labels and section numbers. The layout is asymmetric, like a magazine page.
- **Hero mockup:** a real-looking project list (reprinting a print catalog, with tasks like "it's a heron, not a crane"). It's built in HTML, not a placeholder image, and the checkboxes work and update the counter.
- **No three-icon feature grid:** instead there's a two-column "It does / It doesn't" list, which also says something about the product.
- **Other sections:** a Monday-to-Friday strip showing how a week works, a keyboard shortcut table, one testimonial, a single pricing plan and an FAQ with candid answers. That includes "Are you going to get acquired and shut down?"

It adapts to tablet and phone screens. The signup form checks the email address and shows a confirmation message, but nothing is actually sent anywhere.
