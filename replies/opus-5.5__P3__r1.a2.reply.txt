I've built the portfolio site as a single file, `index.html`, for a fictional photographer called **Ines Varga**. It uses no external fonts, images, libraries or network requests. The JavaScript parses cleanly, but I haven't seen it rendered: no headless browser was available here, so open it locally to check the look.

**Sections**
- **Hero:** a full-screen slideshow that crossfades between three images, with captions and dot controls. It stops auto-advancing if the visitor's system asks for reduced motion.
- **Work:** a grid of 16 pieces that can be filtered by Landscape, Portrait, Editorial or Architecture, with a count on each filter. Clicking a piece opens a full-screen viewer with the title, location, year and camera settings (camera, lens, aperture, shutter speed). The viewer works with arrow keys, Esc and swiping on phones, and keeps keyboard focus inside it while open.
- **About:** a portrait that stays in place while the text scrolls, a short bio, number counters that count up when scrolled into view, and a list of clients.
- **Services:** a light-coloured section listing five services with prices, followed by a four-step process.
- **Testimonials:** rotating quotes with previous/next buttons.
- **Contact:** a form with validation, work-type checkboxes, a date and a budget field. Since there's no server, sending opens the visitor's email app with the message filled in.
- **Layout:** works on phones with a full-screen menu, highlights the current section in the header, and supports keyboard use and screen readers.

**About the images:** to keep the file self-contained, every "photograph" is drawn by code (landscapes, seascapes, skylines, building fronts, portraits and plants, with film grain and darkened edges). To use real photos:
1. Edit the `WORK` list in the script.
2. Replace each item's `svg` value with an `<img>` tag, or point the `scene()` calls at real image files.

All names, clients, quotes, prices and contact details are placeholders. The email address uses the reserved `.example` domain so nothing real gets mailed by accident.
