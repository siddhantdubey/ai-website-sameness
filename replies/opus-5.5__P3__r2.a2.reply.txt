I built the site as one HTML file with no external dependencies: no CDNs, web fonts or image links: **`index.html`** (~48 KB). The JavaScript passes a syntax check, but I haven't opened it in a browser, so please look it over there.

**What's on the page**, for a made-up photographer, *Juno Hale*, based in Lisbon:
- **Hero:** a large serif headline, a booking-status line, and a strip of three images.
- **Gallery:** 15 images in a masonry grid with category filters (Landscape, Portrait, Street, Travel, Night) and counts. Tiles fade in as you scroll.
- **Lightbox:** arrow keys, swipe on mobile, Esc or backdrop click to close, focus kept inside while open, and camera details shown for each image.
- **About:** sticky portrait, bio, numbers that count up, and a client list.
- **Services:** three packages with prices on a dark band.
- **Testimonials and contact:** pill buttons for project type, a budget dropdown, and form checks.
- **Basics:** works on phones (with a menu button), visible keyboard focus, and reduced motion for users who ask for it.

**Notes:**
- **Placeholder images:** All the "photos" are drawn by a small script at load time: mountains, dunes, coast, forest, night skies, street scenes and portraits, with grain and darkened edges. That keeps the file fully self-contained. To use real photos, set `src` on the `data-art` images and replace the `photos` array near the bottom of the script with real image URLs.
- **Contact form:** There's no server behind it. Submitting opens the visitor's email app with the enquiry already filled in, addressed to a placeholder (`hello@junohale.example`). For direct sending, connect it to a form service like Formspree or Netlify Forms.
- **Placeholder text:** The name, bio, clients, prices and testimonials are all invented and need replacing.
